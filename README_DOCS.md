**使用场景：**
- 遇到缓存相关错误
- 开发时定期清理
- 更新代码后

**使用方法：**
```bash
# 给脚本添加执行权限（首次使用）
chmod +x clear-cache.sh

# 运行脚本
./clear-cache.sh

# 然后重启开发服务器
pnpm run dev
```

## 💡 小贴士

### 开发时的好习惯

1. **保持文档打开**
   - 在浏览器中打开 `README_DOCS.md`
   - 遇到问题快速查找

2. **定期清除缓存**
   - 每天开始工作前运行 `./clear-cache.sh`
   - 更新代码后硬刷新浏览器

3. **禁用浏览器缓存**
   - 开发时打开开发者工具
   - 在设置中禁用缓存

4. **记住快捷键**
   - `Ctrl + Shift + R` (Windows/Linux)
   - `Cmd + Shift + R` (Mac)
   - 90%的缓存问题都能解决
