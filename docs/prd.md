# 时鲜管家需求文档

## 1. 应用概述

### 1.1 应用名称
时鲜管家

### 1.2 应用描述
一款智能食材保质期管理应用,通过OCR识别和购物信息爬取,帮助用户记录和管理食材,并在保质期临近时提醒用户及时食用,减少食物浪费。

## 2. 核心功能

### 2.1 语言选择界面
- 启动时显示语言选择UI:用户首次打开应用时展示语言选择界面
- 多语言选项:提供联合国官方语言选择,包括中文、英文、阿拉伯文、俄文、法文、西班牙文、葡萄牙文
- 界面简洁:采用卡片式布局展示语言选项,点击即可切换语言
- 记忆功能:记录用户选择的语言偏好,在后续使用中自动应用

### 2.2 食材录入功能
- 相机拍照识别:用户可通过相机拍摄购物小票,系统自动使用通用文字识别(高精度版)插件识别商品信息
- 图片导入识别:用户可从相册导入小票图片进行通用文字识别(高精度版)插件识别
- 购物信息爬取:支持爬取购物平台界面,自动获取用户购物记录

### 2.3 智能食材管理
- 食材存储:将识别或爬取的食材信息存储到本地数据库的〖电子冰箱〗中
- 保质期计算:自动计算食材距离保质期的剩余天数
- 自动生成保存指南:基于识别的食材信息,调用百度百科和文本生成大模型自动生成保存方法和时间推荐文本
- 食材列表:展示所有已存储的食材及其保质期状态和保存指南

### 2.4 保质期提醒
- 提前3天提醒:在食材保质期前3天向用户发送提醒通知
- 提前1天提醒:在食材保质期前1天再次向用户发送提醒通知

### 2.5 多语言支持
- 支持联合国官方语言:中文、英文、阿拉伯文、俄文、法文、西班牙文、葡萄牙文
- 用户可在设置中自由切换语言
- 系统能根据设备语言环境主动切换界面语言

### 2.6 用户系统
- 注册功能:用户通过邮箱注册账号,注册时系统向该邮箱发送验证码,用户填写正确验证码后完成注册
- 登录功能:已注册用户可通过账号密码、邮箱或手机号登录
- 忘记密码:用户可通过邮箱验证重设密码,系统向用户注册邮箱发送验证码,验证通过后允许设置新密码

## 3. 设计风格
- 配色方案:以清新的绿色为主题色,搭配白色和浅灰色,营造健康、自然的视觉感受
- 图标风格:采用线性图标,简洁明了,易于识别
- 界面布局:采用卡片式布局,食材信息以卡片形式展示,便于浏览和管理
- 视觉细节:使用圆角设计,卡片带有轻微阴影,增强层次感和现代感

## 4. 英文版特殊要求
- 英文版界面中不得出现任何中文字符
- 在中英文无法切换的情况下,优先使用英文作为界面语言
